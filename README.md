# Job application autofill (personal)

- **`extension/`**: Chrome extension that fills Workday, Greenhouse and other application forms from your profile. Use it on its own, one application at a time. See `extension/README.md`.
- **`runner/`**: Python tool that works through a spreadsheet of job links, fills each application with the extension, and leaves it open on Review for you to submit. See `runner/README.md`.

Neither one ever clicks Submit or solves CAPTCHAs.
